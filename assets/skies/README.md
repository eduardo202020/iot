# Cielos inmersivos

Estas texturas son versiones JPG optimizadas para movil, generadas desde HDR
Radiance:

- `morning.jpg`: fuente `mañana.hdr`
- `afternoon.jpg`: fuente `tarde.hdr`
- `night.jpg`: fuente `noche.hdr`

La app las usa como sky dome en el visor inmersivo para evitar fondos negros o
artificiales sin cargar HDR directamente en runtime.
